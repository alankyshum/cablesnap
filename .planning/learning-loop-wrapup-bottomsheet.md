# Learning-loop wrap-up: bottom sheets

## Persisted session learnings

1. **React Native bottom sheet: coordinate pan gesture with inner ScrollView** — In a custom RN bottom sheet built on `Gesture.Pan` and a scrollable body, a single outer `GestureDetector` can swallow vertical touches. Use the RNGH `ScrollView`, track its offset with `onScroll` and `scrollEventThrottle={16}`, compose `Gesture.Simultaneous(pan, Gesture.Native())` with `.activeOffsetY([-10, 10])`, and only let the pan update at the maximum snap point when the scroll offset is at the top and the drag is downward. Bail out of `onEnd` if the sheet did not move.
2. **Bottom sheet content height must track live translateY, not the first snap point** — A body absolutely positioned at `top: SCREEN_HEIGHT` and moved by negative `translateY` has an on-screen height of `-translateY`. Size the animated wrapper from `clamp(min(-translateY, SCREEN_HEIGHT) - headerHeight, 0)` and keep the inner scroll view `flex: 1`, otherwise lower action buttons can remain unreachable.
3. **CableSnap: use plain tsc, not the rtk tsc wrapper, for typechecking** — `rtk tsc --noEmit --pretty` can report no errors while real errors exist; verify with `./node_modules/.bin/tsc --noEmit`.
4. **Reanimated 4: import the named SharedValue type, not Animated.SharedValue** — Use `import Animated, { SharedValue } from 'react-native-reanimated'` and annotate props with `SharedValue<number>`; `Animated.SharedValue<number>` is invalid in Reanimated 4.
5. **accessibilityViewIsModal breaks @testing-library/react-native queries behind modals** — Testing Library v13 excludes background content when `accessibilityViewIsModal` is set. Prefer scoping queries to the modal or closing it before querying background content; gating the prop in tests is only a code-smell stopgap and must be flagged as a production/test divergence.
